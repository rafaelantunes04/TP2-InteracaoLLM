## ⚖️ Créditos e Agradecimentos

Este projeto utiliza o dataset **SKU-110K**. Todos os direitos sobre as imagens e anotações originais pertencem aos seus respetivos autores e à Trax Retail. O dataset é utilizado aqui com fins estritamente académicos e não-comerciais.

Para mais informações sobre o dataset, visita o repositório oficial: [eg4000/SKU110K_CVPR19](https://github.com/eg4000/SKU110K_CVPR19).

Se o teu trabalho também derivar deste projeto ou utilizar estes dados, por favor, garante que dás o devido crédito aos autores originais citando o seu artigo:

> Goldman, E., Herzig, R., Eisenschtat, A., Goldberger, J., & Hassner, T. (2019). *Precise detection in densely packed scenes*. In Proceedings of the IEEE/CVF Conference on Computer Vision and Pattern Recognition (pp. 5227-5236).
